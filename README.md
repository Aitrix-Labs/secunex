# Secunex — React Clone

Pixel-faithful React recreation of [secunex.com](https://www.secunex.com/) homepage.

## Stack

- Vite + React + TypeScript
- Custom CSS matching live design tokens (Geist, General Sans, Literata)
- Assets loaded from Secunex’s CDN for visual parity

## Run

```bash
npm install
npm run dev
```
